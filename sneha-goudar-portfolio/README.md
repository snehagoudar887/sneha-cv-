# Sneha Basavaraj Goudar — Personal Portfolio Website

A complete, responsive, modern developer portfolio website built with **React**, **Vite**, and **Tailwind CSS**.

## 🛠️ Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Fonts:** Space Grotesk & DM Sans

---

## 🚀 Local Setup & Instructions

### 1. Extract & Open Project
Extract the `sneha-goudar-portfolio.zip` file into a local folder and open it in VS Code or your preferred code editor.

### 2. Install Dependencies
Run the following command in the project terminal:
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to GitHub Pages

1. Create a public repository named `sneha-portfolio` on your GitHub account.
2. Initialize git and push source files:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit for Sneha Basavaraj Goudar"
   git branch -M main
   git remote add origin https://github.com/snehagoudar887/sneha-portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository settings, navigate to **Pages** and configure deployment source.

## ✏️ Centralized Content Updates
