# Sneha Basavaraj Goudar — Portfolio

React + Vite portfolio configured for the GitHub Pages project site:

https://snehagoudar887.github.io/sneha-cv-/

## Publish on GitHub Pages

1. Upload the contents of this folder to the **root** of the `sneha-cv-` repository (not inside another nested folder).
2. Commit the changes to the `main` branch.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment → Source**, select **GitHub Actions**.
5. Open the **Actions** tab and wait for the **Deploy portfolio to GitHub Pages** workflow to finish successfully.
6. Visit https://snehagoudar887.github.io/sneha-cv-/ after the workflow succeeds. It can take a few minutes to update.

## Run locally

Install Node.js, then run:

```bash
npm install
npm run dev
```

To test a production build:

```bash
npm run build
```

Portfolio content is organized in `src/data/portfolioData.js`.

Do not publish unverified personal details or certificate links. Confirm all profile details with Sneha before publishing.
